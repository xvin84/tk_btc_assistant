# История версий

Формат вдохновлён [Keep a Changelog](https://keepachangelog.com/ru/);
версии — [SemVer](https://semver.org/lang/ru/). Полные диффы — в
[релизах GitHub](https://github.com/xvin84/tk_btc_assistant/releases).

## [0.3.0] — 2026-10-14

**Программа заговорила по-английски и собирается под Linux и macOS.**

- **Язык интерфейса**: русский или английский, переключается на вкладке
  «Справка» (блок «Язык / Language») и запоминается. При первом запуске
  берётся язык системы. Переведены окно, журнал, причины остановки и ошибки
  adb; командная строка по-прежнему говорит по-русски. Языки устроены как в
  Adalight: ключами служат русские строки (`tr("Проверить")`), а тест следит,
  чтобы у каждой строки был перевод с теми же подстановками.
- **Сборки для Linux (x86_64) и macOS (Apple Silicon)** рядом с Windows: CI
  собирает все три, запускает самопроверку каждой программы и выкладывает
  архивы в один релиз. На macOS настройки и логи лежат в
  `~/Library/Application Support/BtcAssistant` (внутрь `.app` писать нельзя),
  а adb ищется и там, куда его ставят Homebrew и Android Studio.
- **Собранная программа стала легче**: распознавание в ней идёт через numpy и
  Pillow вместо OpenCV. Кадр считается ~80 мс вместо ~30 мс, что незаметно на
  фоне ~0,9 с на сам снимок экрана, а OpenCV с его ffmpeg занимал 60–150 МБ.
  При запуске из исходников OpenCV остаётся.
- **Репозиторий оформлен как остальные**: README на английском и русском,
  история версий на двух языках, текст релиза собирается из неё
  (`scripts/release_notes.py`), шаблоны issue — ошибка, идея и отдельный
  «Бот не узнаёт экран» для кадров поражения, окна стамины и прочего.

## [0.2.1] — 2026-10-14

**Превью больше не отстаёт от телефона.** Картинка в окне опаздывала на 3–5
секунд: `screencap -p` на экране 2780×1264 сжимает PNG прямо на телефоне и
занимает 1,5–3 секунды, сверху добавлялись пауза бота в секунду и обновление
превью раз в секунду. А пока бот не запущен, картинка вообще стояла на месте.

- **Новый способ снимка экрана `gzip`** (по умолчанию): сырой кадр сжимается
  на телефоне быстрым `gzip -1` — около 0,9 секунды по кабелю вместо 1,5–3.
  Если gzip на телефоне нет, бот сам переходит на PNG.
- **Пауза между снимками** — 0,3 секунды вместо секунды: бот заодно быстрее
  реагирует на смену экранов.
- **Кадр показывается сразу**, как только бот его снял.
- **Живой экран, пока бот не запущен**: окно само снимает телефон, а строка
  «Игра» загорается, когда открыта карта кампании, — без повторного
  «Проверить». Итог прошлого запуска при этом остаётся в карточке статуса.

## [0.2.0] — 2026-10-14

**Окно на Qt вместо Tk.** Python, который ставит uv, приходит с Tk без
шрифтов, и на Linux вместо кириллицы в окне были пустые места. Окно
переписано на PySide6 в стиле Adalight:

- тёмная тема, боковое меню (Телефон, Настройки, Справка), карточка статуса с
  кнопкой «Запустить»/«Остановить», превью экрана в пропорциях игры, счётчики
  и журнал справа;
- русские подписи стандартных кнопок диалогов;
- тесты окна без экрана (Qt offscreen): проверка телефона, полный забег на
  подставном телефоне, остановка кнопкой;
- забег больше не описывается как «5 боёв»: бот считает экраны «ПОБЕДА», а
  сколько в забеге боёв, ему неважно;
- сборка без Tk, лишних переводов Qt и программного OpenGL; самопроверка exe
  в CI поднимает окно в режиме offscreen.

## [0.1.0] — 2026-10-14

Первый публичный выпуск.

- **Автопрохождение цепной кампании**: «Старт» → «СТАРТ» → контроль «АВТО» →
  победа → «Получить все» → награды → повышение глубины → следующий забег.
  Экраны узнаются по шаблонам надписей и кнопок (OpenCV) в рабочем масштабе
  1280 px; затемнённые кнопки под всплывающими окнами не нажимаются.
- **Остановки**: при поражении (с закрытием игры по желанию), при нехватке
  стамины и на незнакомом экране — без лишних нажатий, с кадром для отчёта.
- **Окно программы**: проверка телефона, скачивание adb с сайта Google,
  настройки, пробный режим, превью экрана, журнал.
- **Сборка для Windows** (PyInstaller) и релизы через GitHub Actions по тегу.
- **Запуск прямо на телефоне через Termux** и распознавание без OpenCV
  (numpy + Pillow). Этот режим пока не проверялся на живом телефоне.
- Командная строка: `run`, `doctor`, `record`, `snap`, `classify`, `crop`,
  `rebuild-templates`, `connect`, `pair`.
