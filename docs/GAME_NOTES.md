# Заметки по механикам (для будущей боевой логики)

По опыту игры и досье отряда (данные из игровых таблиц, tkgbtc.com).

## Цепная кампания

- Глубина (уровень) кампании, например 317. На карте 8 этапов и босс, этап `317-8`.
- Этап — забег из 5 боёв подряд пятью отрядами («Расстановка»).
  Следующий бой начинается сам, а выход посреди боя засчитывается как поражение.
- Чем меньше ходов, тем выше оценка. S — бой за 5 ходов («Завершите бой за 5 хода(ов)»).
- S на всех этапах запускает «цепную реакцию»: этапы закрываются, на карте
  появляются сундуки и кнопка «Получить все», затем глубина растёт (317 → 318).
- Стоимость старта: стамина (на скриншоте 30, со скидкой 15).

## Бой

- В руке 7 карт. За ход можно сделать **не больше 4 действий**: сыграть карту,
  применить ульту или переставить карту. Действия энергию не тратят.
- Две одинаковые карты рядом сливаются: правая «въезжает» в левую, уровень +1, максимум 3.
- Слияние **до 3-го уровня** даёт «высвобождение силы»: такая атака вешает
  1 Weak на всех врагов (3 Weak, если атрибут цели слабый против нашего).
  Карта, ставшая 3-го уровня не слиянием, высвобождения не даёт.
- Weak на максимуме оглушает врага на 1 ход.
- Типы карт: атака и заряд ульты (карта 1/2/3 уровня даёт 20/50/100%).
  Ульта на практике почти бесполезна, своя логика может её не использовать.
- Цель атаки выбрать можно.
- Встроенный автобой есть (кнопка «АВТО»: золотая — включён, серая — выключен).

## Атрибуты

```
Сила › Техника › Скорость › Сила
Психика ⇄ Интеллект
Уничтожение › все
```

Урон по уязвимому атрибуту ×1,5. Схема есть в правом верхнем углу экрана боя.

## Что нужно для своей боевой логики

- распознавание карт в руке: персонаж (по портрету), атрибут (значок), уровень (звёзды);
- распознавание врагов: атрибут, HP, число Weak;
- записи нескольких ручных боёв (`uv run btc-bot record`), чтобы проверить
  правила на реальных раскладах.
